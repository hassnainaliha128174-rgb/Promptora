Code Debugging Assistant

Diagnose and fix a coding problem.

Full prompt

Act as a senior software engineer.
Language/framework: [LANGUAGE]
Code:
[CODE]
Error or problem:
[ERROR]

Analyze the code. Identify syntax errors, logic problems, edge cases, performance concerns and security issues when relevant. Explain the root cause, provide corrected code, explain the important changes and give practical test cases. Preserve the intended behavior unless a change is necessary. Do not claim to have executed the code.
