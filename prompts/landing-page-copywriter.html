Landing Page Copywriter

Write conversion-focused but truthful landing-page copy.

COPY-READY PROMPT

Full prompt

Act as a conversion copywriter.
Product/service: [PRODUCT]
Audience: [AUDIENCE]
Customer problem: [PROBLEM]
Verified benefits: [BENEFITS]
CTA: [CTA]

Write landing-page copy with a clear hero section, value proposition, problem/solution section, benefits, feature explanation, trust section using only supplied proof, FAQ and CTA. Avoid fabricated testimonials, statistics, guarantees and urgency. Keep the copy concise and scannable.
HOW TO USE
