Personal Workflow Optimizer

Improve a repetitive workflow without adding unnecessary complexity.

COPY-READY PROMPT

Full prompt

Act as a workflow improvement consultant.
Current workflow: [WORKFLOW]
Tools: [TOOLS]
Main bottleneck: [BOTTLENECK]

Map the current process, identify unnecessary steps, propose a simpler workflow and define quality checks. Recommend automation only where it clearly saves time. Include a before/after process and a short implementation checklist. Avoid recommending unnecessary paid software.
HOW TO USE
  1. Copy the prompt.
  2. Replace the values inside [brackets].
  3. Paste it into your preferred AI tool.
  4. Review the result and refine your inputs.
